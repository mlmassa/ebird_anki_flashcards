# ebird_anki_flashcards
R script to generate Anki flashcards for a given eBird region(s) and time period. Meant to provide easy spaced-repetition studying to familiarize yourself with birds in a new region.
Run the attached R script line by line, paying attention to choices provided throughout.

## Important notes
* Only tested on Windows.
* You will need to be logged into an eBird account to access the frequency bar chart data. The eBird API does not currently support direct download of bar chart data, and it is locked behind the login screen. Take it up with them!
* Please excuse any jank. :)
* Only pulls the first image in eBird (the same image used for Merlin), which is usually an adult male. Very gauche and unrepresentative!
